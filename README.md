# 🎧 TTS VOICE READER (EDGE-TTS)

**Công cụ chuyển đổi văn bản sang giọng đọc tự nhiên và nghe trực tiếp trên ứng dụng (100% Miễn phí, không cần cấu hình)**

---

## 🌟 ĐẶC ĐIỂM NỔI BẬT

1. **Nghe trực tiếp trên App:**
   - Dán văn bản hoặc mở file tài liệu -> Bấm **[▶ ĐỌC VĂN BẢN (NGHE NGAY)]** để thưởng thức âm thanh ngay lập tức.
   - Hỗ trợ đầy đủ các nút: **▶ Phát**, **⏸ Tạm dừng**, **▶ Tiếp tục**, **⏹ Dừng lại**.
   - Không yêu cầu chọn thư mục lưu hay quản lý file rườm rà; âm thanh được tối ưu phát mượt mà trực tiếp.

2. **Giọng đọc độc quyền: Nam Minh (Nam - Tiếng Việt):**
   - Trầm ấm, dõng dạc, phát âm chuẩn tự nhiên.
   - **Tối ưu tốc độ tối đa:** Khóa duy nhất giọng đọc Nam Minh để loại bỏ hoàn toàn hiện tượng lỗi âm vị hay treo timeout 10s từ các giọng đọc khác.
   - Tùy chỉnh trực quan: Tốc độ đọc (`-30%` đến `+40%`) và Cao độ giọng (`Pitch`).

3. **Hỗ trợ đa định dạng tài liệu:**
   - Nút **📂 Tải File** hỗ trợ mở nhanh: Text (`.txt`, `.md`), Word (`.docx`), PDF (`.pdf`), Ebook (`.epub`).
   - Nút **📋 Dán nhanh** từ bộ nhớ tạm (Clipboard) và nút **🗑 Xóa trắng**.
   - Tự động thống kê số từ, ký tự và ước tính thời lượng nghe.

4. **Giao diện hiện đại & Độc lập:**
   - Hỗ trợ Chế độ Tối (Dark Mode) và Chế độ Sáng (Light Mode).
   - Chạy độc lập trên máy tính, dữ liệu riêng tư 100%, không tốn chi phí API.
